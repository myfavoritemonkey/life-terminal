# Жизнь — терминальная игра

## Версия на Fortran

Нужны `gfortran`, `make` и терминал с поддержкой ANSI. Сборка и запуск:

```bash
cd /home/pc/projects/life-terminal
make
./life
```

По умолчанию поле занимает почти весь терминал (для окна 120×40 — поле 118×38). Если размер терминала не определяется, используется поле 100×30. Размер поля и начальную скорость можно задать при запуске, например:

```bash
./life --width 120 --height 35 --speed 10000
```

По умолчанию каждое поколение заполняется случайно заново: каждая клетка жива с вероятностью 25%. Новые живые клетки белые и постепенно становятся серыми, если остаются живыми; следы погибших клеток синеют, затем исчезают за 0,9 секунды. На высокой скорости возраст для цвета считается по наблюдаемым состояниям между пачками шагов. `T` включает и выключает следы. `C` переключает на классические правила Конвея и обратно. `Пробел` приостанавливает и продолжает игру, `R` возвращает исходное поле к нулевому поколению, `N` создаёт новое случайное поле, `+` и `-` удваивают и уменьшают вдвое скорость от 1 до 10 000 шагов/с, `Q` или `Ctrl+C` завершают игру. В режиме Конвея поле замкнуто по краям. Частота отрисовки ограничена 20 кадрами/с; при высокой нагрузке фактическая скорость может быть ниже выбранной и показывается в строке состояния. Для подсказок на экране терминал должен быть не уже 75 символов.

При запуске открывается меню сцен. Нажмите `0` для случайного поля или `1`–`5` для отдельной фигуры: неподвижный блок, блинкер, глайдер, R-пентамино и [пушка Госпера](https://www.brianlane.com/git/sdl2-life/file/examples/glider-gun.rle.html). Пушка выпускает по глайдеру каждые 30 поколений. В сценах действуют обычные, незамкнутые границы; для пушки нужно поле не меньше 40×14, а на большом терминале полёт глайдеров виден дольше. `M` возвращает в меню сцен, `R` перезапускает выбранную сцену.

Проверить правила игры: `make test`.

## Версия на Python

Интерактивная игра по правилам клеточного автомата Конвея. Есть свободная песочница и шесть испытаний. Нужен Python 3.10+ и терминал размером хотя бы 48×15. Зависимости не требуются.

```bash
cd /home/pc/projects/life-terminal
python3 game.py
```

| Клавиши | Действие |
| --- | --- |
| Стрелки или WASD | Переместить курсор |
| Пробел или щелчок мышью | Добавить или убрать клетку |
| Enter | Запустить или остановить симуляцию |
| N | Сделать один шаг |
| 1–5, P, X | Выбрать фигуру, поставить, повернуть |
| T | Перейти к следующему режиму |
| C | Очистить поле или начать испытание заново |
| R | Случайное поле в песочнице |
| B | Переключить сквозные границы |
| + / - | Изменить скорость |
| H | Показать помощь |
| Q или Esc | Выйти |

## Испытания

| Испытание | Цель | Стартовых клеток | Срок |
| --- | --- | ---: | ---: |
| Выживание | Дожить до 12-го поколения | 4 | 12 |
| Вспышка | Вырастить 20 живых клеток | 5 | 30 |
| Пульс | Сохранить колебание с периодом 2 до 6-го поколения | 3 | 8 |
| Улей | Получить неподвижную фигуру из 6 клеток к 10-му поколению | 6 | 10 |
| Путешествие | Сдвинуть исходную фигуру на 6 клеток | 5 | 16 |
| Буря | Вырастить 30 живых клеток | 5 | 40 |

В испытаниях клетки ставятся до первого шага. Сквозные границы и случайное заполнение доступны в песочнице. Рекорды сохраняются в `scores.json`.
